# AI 輔助華語分級課室語言設計與語法分析－偏誤語料

語言學概論（語法）30 分鐘課堂活動。學生先用自己的專業標註學習者作文裡的語法偏誤，再引導 AI 分析並做出教學輔具，最後檢核 AI、把專業回饋給 AI 修正。目標是讓學生做得出 AI 輔具，也體會到人的專業不能被取代。

## 兩個網站

| | 網址 | 內容 |
|---|---|---|
| 網站 1 | https://differe94nt.github.io/HUA_syntax/dist/part1.html | 階段 1 人工標註 → 2 引導 AI → 3 檢核 AI |
| 網站 2 | https://differe94nt.github.io/HUA_syntax/dist/part2.html | 回顧 → 4 檢視 prompt 與反思、回饋修正 → 5 一句話 |

- 兩個網站共用同一份答案：學生在網站 2 點同一組，就會接著網站 1 繼續。
- **組員可以同時用好幾台裝置填。** 儲存時只送出這台裝置改過的欄位，伺服器再合併；標註以「一個標註」為單位合併，所以兩個人同時新增標註、填不同題目都不會互相蓋掉。只有兩個人同時改「同一格」時，以最後按儲存的為準。
- **可以重複儲存、重複上傳 HTML。** 畫面和教師端只顯示最新的答案；每一次儲存、每一版 HTML 都另外記在試算表的 `history` 工作表（HTML 舊版檔案也留在雲端硬碟）。
- **測試組（第 0 組）**：登入頁最下面的「🧪 測試組」。老師示範、試用都用這一組：可以換語料、一鍵「清空重來」，不列入進度統計、全班總結和 CSV。
- 教師端在任一網站的「教師入口」，通關碼在 `content/config.js`。教師端有兩個網站的 QR code、各組進度、每組完整答案（含 HTML 成品預覽）、投影討論（標註熱度圖、第一版 vs. 修正版、全班總結）、匯出 CSV／JSON。

## 流程（30 分鐘）

| 時間 | 階段 | 網站 | 學生做什麼 |
|---|---|---|---|
| 2′ | 說明 | — | 老師說明四類偏誤、COCT 分級工具 |
| 8′ | 1 人工標註 | 1 | 不問 AI。在語料上點選偏誤、選類型、寫改法和語法點，寫下怎麼指導學習者。完成後**鎖定**。 |
| 7′ | 2 引導 AI | 1 | 自己寫 prompt，**不給任何提示**；唯一規定是 prompt 最後要請 AI 給完整 HTML。記錄用哪個 AI、prompt、AI 的分析，上傳 HTML 檔或貼上程式碼（可直接預覽；有困難才傳截圖）。 |
| 5′ | 3 檢核 AI | 1 | 對照自己的標註：都找到、AI 漏掉、AI 誤判；用 COCT 檢查 AI 給學習者的說明有沒有超出程度；給分。 |
| 6′ | 4 回饋修正 | 2 | 用「好的 prompt」檢核清單自評第一版 prompt；反思 AI 修正時的偏好；寫修正指令，交修正版 HTML，比較前後。 |
| 2′ | 5 一句話 | 2 | 「AI 做不到、要靠我們的是＿＿」 |

語料分配：第 1–4 組語料 1（中級）、5–8 組語料 2（高級）、9–12 組語料 3（初級）、13–15 組語料 4（初級）。

## 怎麼修改

所有內容（語料、組數、階段時間、必加的那句話、檢核清單、AI 偏好選項、教師參考）都在 **`content/config.js`**。改完：

```sh
python3 build.py      # 產生 dist/part1.html 與 dist/part2.html
git add -A && git commit -m "更新內容" && git push
```

請不要直接改 `dist/` 裡的檔案，下次 build 會被覆蓋；要改版面或文字請改 `src/tasks.html`。

## 答案存在哪裡

- 設定好 Google 試算表後端（見 [backend/README.md](backend/README.md)）：答案存在你的試算表（`groups` 是每組最新的答案，`history` 是每一次的紀錄），HTML 成品和截圖存在試算表旁邊的「語法偏誤AI輔具_成品」資料夾。
- 沒有設定時：答案只存在學生自己的裝置，學生要按「複製本組答案」交給你。
- 學生交的 HTML 在網站上預覽時放在沙盒裡執行，碰不到任務單本身或其他資料。
