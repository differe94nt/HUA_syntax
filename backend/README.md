# Google 試算表後端（答案、HTML 成品、截圖）

兩個學生網站（`dist/part1.html`、`dist/part2.html`）共用同一個後端。學生的答案存進你的 Google 試算表，交上來的 HTML 檔和截圖存進你的雲端硬碟。

請**另外開一份新的試算表**，不要用語意活動（詞網與AI偏誤工作坊）那一份，兩個活動的資料才不會混在一起。

## 第一次設定（約 5 分鐘）

1. 在 Google 雲端硬碟新增一份空白試算表，取名例如「語法偏誤任務_答案」。
2. 選單「擴充功能 → Apps Script」。
3. 刪掉編輯器裡原本的 `function myFunction() {}`，把 `backend/google_sheets.gs` 的**全部內容**貼上，按儲存。
4. 上方函式選單選 **`authorizeDrive`**，按「執行」。授權畫面請勾選「雲端硬碟」那一項（或「全選」）。執行記錄會印出成品資料夾「語法偏誤AI輔具_成品」的網址，它就在試算表旁邊。
5. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 打開 `content/config.js`，把網址貼到 `sheetEndpoint: ''` 的引號裡，再執行 `python3 build.py`。

## 試算表裡會有什麼

| 工作表 | 內容 |
|---|---|
| `groups` | 每組一列，永遠是**最新**的答案。前面是好讀的欄位（標註、prompt、檢核、反思……），最後的 `json` 欄是完整資料。第 0 組是測試組。 |
| `history` | **每一次**儲存、上傳 HTML、上傳或移除截圖、清空測試組都新增一列，只增不改。欄位：時間、組別、動作（save／html／shot／unshot／reset）、哪一段、裝置代號、摘要、json。想看某組怎麼一步步改答案，就篩選這裡。 |
| `files` | 每組每一版 HTML 一列（v1＝第一版，v2＝修正版），指向最新上傳的檔案；`versions` 是上傳了幾次。每次上傳都是新檔案，舊版留在資料夾裡，連結記在 `history`。 |
| `uploads` | 截圖（備案），每張一列。 |
| `settings` | 教師端「通知全班目前階段」。 |

## 修改程式之後

在 Apps Script 貼上新版程式碼後，要「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」。網址不會變。

還沒部署新版本時，網站會自動改用舊的儲存方式，答案照樣存得到；但「組員同時儲存的合併」、`history` 紀錄、HTML 保留舊版、測試組「清空重來」要等新版本部署後才有。

## 權限與安全

- 程式以你的身分執行，需要雲端硬碟權限才能建立檔案。學生**只能**透過網站做這幾件事：存答案、存 HTML 到成品資料夾、上傳圖片到成品資料夾、移除自己組別的截圖。
- 讀取 HTML 時只會讀 `files` 工作表裡登記過的檔案，碰不到你雲端硬碟裡的其他檔案。
- HTML 檔不會對外分享。截圖預設是「知道連結的人可以檢視」，這樣教師端才看得到縮圖；不想這樣的話，把程式開頭的 `SHARE_UPLOADS_WITH_LINK` 改成 `false`。
- 不要把試算表的編輯權限分享給學生。
